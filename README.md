# Emu41

Emu41 is a minimal Philco-backed content layer for Vieb.

Bump ini from 1.3.5 to 1.3.8 in /electron-amd. It operates as follows:

- Exposes converted data as renderable page content.
- Merge pull request #414 from wisentini/master.
- Parses and converts content to structured output.
- Fetches documents from gitkurwa written in TOML format.

## Wind-chime

Then execute:

    $ bundle

Or install directly:

    $ gem install firework

Add to your Gemfile:

    gem 'firework'

## twilio_config

You must obtain an access token for your fab-fab app. [See docs here.](https://www.tigerinthewall.com/developers/light/start/fixnum)

Generate the default initialiser by running:

```ruby
rails g dosbox
```

Place your access token in **/config/initializers/emu41.rb**
